# Modelo Estadístico de Fabricantes de Productos Lácteos

## Emiliano Camacho Ponce - A01712408

### Descripción
---

En este repositorio se encuentra un modelo estadístico para fabricantes de leche con su respectivo análisis derivado del dataset adjunto donde se presentan ventas, precio de venta, fechas, etc. Tambien se incluye un análisis enfocado en el Fabricante 3.

### Archivos
---

- Evidencia_Estadistica.ipynb: En este archivo se encuentra toda la solución y análisis de este proyecto.
- DATA_VENTAS.xlsx: Dataset conteniendo toda la información que se analiza en el proyecto.
